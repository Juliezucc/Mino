# Autoriser l'exploration, et n'interdire QUE l'indexation.
#
# Ce fichier a d'abord porté `Disallow: /`, ce qui paraît plus prudent et ne
# l'est pas. Un robot à qui l'on interdit de charger la page ne lit jamais
# l'en-tête `X-Robots-Tag: noindex` qui lui est destiné — il ne voit donc
# jamais l'interdiction, et Google peut faire figurer l'adresse nue dans ses
# résultats, avec « Aucune information n'est disponible pour cette page ».
# C'est le comportement que Google documente lui-même : pour tenir une page
# hors des résultats, il faut la laisser explorer et lui servir un `noindex`.
#
# Le cas n'est pas théorique ici : le certificat Let's Encrypt d'
# app.minoapp.fr est passé dans les journaux de transparence, l'adresse
# circule donc déjà sans qu'aucun lien ne pointe vers elle.
#
# ⚠️  L'INTERDICTION N'EST PAS DANS CE FICHIER. Elle est dans `.htaccess`, sur
# la ligne :
#
#     Header always set X-Robots-Tag "noindex, nofollow, noarchive, nosnippet, noimageindex"
#
# C'est celle-là qu'on supprime le jour du lancement — voir
# docs/ops/avant-de-lancer.md. L'oublier ne casse rien et ne se voit pas : le
# site marche parfaitement, il n'apparaît simplement jamais dans un moteur de
# recherche, et l'on met trois mois à se demander pourquoi le référencement ne
# décolle pas.

User-agent: *
Allow: /
